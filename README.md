## ▶️ How to Run a Project

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/flutter-ui-projects.git
cd flutter-ui-projects
```

---

### 2️⃣ Install Dependencies

```bash
flutter pub get
```

---

### 3️⃣ Run Any File

Replace `main.dart` with the file you want to run:

```bash
cp lib/to_do_app.dart lib/main.dart
flutter run
```

---

## 📌 Notes

- Each `.dart` file contains its own `main()` function  
- All apps are **independent and standalone**  
- No backend or API is used  
- Some apps use **static/mock data**  
- Focus is on **UI & navigation concepts only**
